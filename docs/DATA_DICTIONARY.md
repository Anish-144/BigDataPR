# Data dictionary

Generated by `python -m docs.generate_docs dictionary` from the live lakehouse schema on 2026-10-10. Catalog `lakehouse`, schema `analytics`; Apache Iceberg (format v2) tables stored as Parquet/ZSTD on MinIO.

Privacy & retention assumptions: all data is synthetic (fictional company, synthetic canary secrets). Raw prompts/answers are not stored unless CAPTURE_CONTENT=true (then redacted, truncated previews only). Kafka retains 7 days; Iceberg snapshots older than 7 days are expired by the lakehouse_maintenance DAG.
