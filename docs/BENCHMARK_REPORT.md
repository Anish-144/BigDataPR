## Detector iteration log

Security rule v1 (before fix): 732 false-positive findings from benign document KB-020; prompt-injection detection 90.1%. Fixes: indicator requires an explicit destination (email address or URL); prompt_injection fault guarantees the poisoned document is retrieved (exposure), incompatible with failed_retrieval; malformed outputs are truncated at the tail only; canary placed at the start of the answer; retrieval excludes documents with zero lexical overlap (min score).
